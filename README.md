Ollama AI Chatbot

A simple AI chatbot built using Python and Ollama.

Technologies Used

- Python
- Ollama
- Llama 3.2

Features

- Answers user questions
- Generates AI responses
- Runs locally on your computer
- No OpenAI API key required

Installation

1. Install Ollama.

2. Download the model:
   
   "ollama pull llama3.2"

3. Install Python library:
   
   "pip install ollama"

Run the Project

"python chat_bot.py"
